## 四、已知边界（诚实声明，非 mock）

- **浏览器物理边界**：无 Node 运行时（npm/tsc 不可用已明示）；无平台 OAuth 代发（发布=复制+开后台）；直连 GitHub 等需 CORS 代理（Git remote 明示）。
