### 3.2 核心故障场景回滚演练（实弹，隔离环境零风险）

```bash
# 演练环境：YYC3_PAI_HOME=/tmp/pai-drill-home（已清理）
uv run pai init --admin-username drilladmin --yes        # ① 初始化

uv run pai --json user list        # → drilladmin + drilluser 完整回归 ✅
```

**结论：备份→灾难→恢复闭环 100% 有效**；恢复清单自带 schema 版本与驱动信息，应急排障路径清晰。

## 五、生产上线后运维建议与监控重点

1. **监控重点**：`/api/health` 的 `db` 字段（SQLite/PG 连通性）+ `agents_running` 骤降；磁盘水位（SQLite WAL + 工作区增长）；auto backup 是否按 schedule 产出（`pai backup auto status`）。
2. **告警接入**：自托管形态建议外挂 Uptime Kuma/健康检查拨测 `/api/health`，失败即通知。
3. **备份纪律**：生产必开 `auto_enabled`（cron 调度仅在有活进程时运行）；升级前手动 `pai backup create` 一次。
4. **升级/回滚 SOP**：`pai update`（绿色包目录保留旧版本）→ 异常时回滚至旧目录 + `pai backup restore`；数据库迁移只进不退，回滚=旧版本程序 + 恢复备份。
5. **安全基线**：定期轮换 JWT secret 与管理员凭据；反向代理 TLS 终止或启用内建 Let's Encrypt；关注 CodeQL 每周扫描结果。
