## 三、关键决策记录

| 决策 | 原因 |
| --- | --- |
| Fork-and-Own 而非全量重写 | 四包全 MIT、harness 大脑在 langchain 生态；重写 ROI 低；四包强耦合（harness→memory+browser）必须整体接管 |
| 仅改发行名、保留 `octop_*` 模块名 | 主仓调用点 <50 但保留模块名可零改动兼容，把分叉成本压到最低 |
| 版本线重置为 0.1.0 | 身份独立，与上游版本号脱钩 |
| 语言资产生成入库 | npm 3.0.2 exports 未暴露 ./locales；入库 JSON 保证无兄弟仓也可构建 |
