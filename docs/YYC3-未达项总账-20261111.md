## 三、待修缺陷（🟡 甄别队列，按组件分组）

### 3.1 layout-engine（3）
- `TransformOptions.title` 死参数（接收但从未使用）
- `extra['hr']` 默认回退不可达（六平台全定义）
- 截断按字符 `slice` 硬切，twitter 280 上限下必产生残缺 HTML 标签

### 3.2 local-model-infra（5）
- `scanAllNodes` 双重解析不一致：capabilities 用宽松匹配、path/isFinetuned 用精确匹配（带标签模型能力匹配但路径丢失）
- `matchCapabilities` 双向前缀匹配过宽（短名/子串错配到无关模型）
- `KNOWN_MODEL_CAPABILITIES` 别名经归一化后与原名相同（冗余死数据）
- dgx-spark-1/2、cloud-33/202 有节点配置但零模型资产（默认模型恒 undefined）
- `saveNodeState` 展开后四字段重复赋值（冗余）

### 3.3 sync-backend-adapter（3）
- `LocalFileBackend.connect` try/catch 为死代码（同步赋值不抛出）
- `getConfig()` 浅拷贝泄漏 backends 引用（外部可改内部状态）
- `loadConfig` 异步重连失败无回退标记（promise 链无 catch）

### 3.4 native-database-dumper（5 次要）
- `compress:true` 且 format 缺省（纯文本 SQL）仍拼 `-Z9`（真 pg_dump 拒绝）
- `stat -f%z` BSD 专有（Linux 桌面端失败）
- `restoreSQLite` 的 cp 路径未走 `shellQuote`（转义纪律不一致）
- restore 成功返回 `tablesRestored: -1` 哨兵值（契约怪异）
- `detectNativeEnvironment` 第二条件死分支

### 3.5 data-portability（2，除 P1-a/b）
- 解密失败被归类为 file 级 `invalid_format`（应为 `decryption_failed`）
- ZIP 压缩路径未覆盖（659-713）

### 3.6 RichTextEditor（3）
- 翻译目标语言闭包过期（切语言后首次翻译方向错）
- Tiptap v3 `shouldRerenderOnTransaction:false` 致工具栏/状态栏/AI 菜单禁用态滞后
- 字数恒 0（未注册 CharacterCount 扩展）

### 3.7 CRDT / CyberEditor（2）
- CyberEditor 依赖抖动：`useCollabStore()` 每渲染新对象→effect 每次 destroy→init（持续编辑期协作模拟永不触发）
- （P1-c 已列于阻塞）

### 3.8 audio-engine（6，除 P1-d）
- 命名音效键永不命中（`registerSoundEffect` 用 uuid 池键，`playUIClick` 等查固定键→五分支死代码，始终回退合成器）
- 构造顺序：`initializeAudioContext` 先于 `loadFromStorage`，恢复的 masterVolume 不作用于 gainNode
- `playEditedVersion` fadeOut 单位混用（ms 与 s 相减，定时器可能负值）
- `inferTags` 专辑启发式过宽（`includes('a')` 命中几乎所有专辑；合唱标签重复）
- `play()` 切歌只 stop 不 unload（Howler html5 节点累积）
- 上传大文件错误回调缺失（FileReader 错误路径）

### 3.9 EnhancedBackupRestorePanel（1）
- 「直接恢复」按钮 onClick 与预览相同（tooltip 承诺跳过确认，实际永远走预览）

### 3.10 WorkflowPanel 遗留（1）
- `executeWorkflow` 完成后不清理 `executingWorkflowId`（P0 已修，此为遗留状态未复位）

**小计：约 31 项待修（其中 P0/P1 四项）。**
