1. **项目本体是健康的**：在与 CI 一致的 pnpm 9 环境下，`type-check`、`eslint`（75 警告 < 阈值 76）、**2810 个单元测试全部通过**、生产构建全部成功。测试/类型/构建基线全绿。

### 2.2 mimosa 深度静态扫描（sealed report）

- 扫描结论：**inconclusive**（调用图部分不完整，覆盖率 partial），4 个静态发现：
  - 3 × HIGH 路径穿越：`docs/YYC3-团队通用-标规文档/YYC3-团队文档-引擎模版.py:342,405`、`scripts/fix_md_headers.py:84` —— 均为本地脚本/文档模板对含 `../` 路径未校验，属低风险（非线上攻击面），建议顺手加 `resolve()` + 前缀校验；
  - 1 × HIGH SSRF：`src/app/hooks/usePerformanceMonitor.tsx:261` —— **经人工核实为误报**：代码是浏览器端 `fetch(window.location.href, {method:'HEAD'})` 测网络延迟，不构成服务端请求伪造。

### 2.3 依赖漏洞审计（pnpm audit，lockfile 口径）

- 2 个 critical：`protobufjs`（任意代码执行，升级 ≥7.6.1 可全覆盖）、`tar`（解压 DoS，≥7.5.21）——主要是构建链/传递依赖，不直接进 bundle；
- 57 个 high 里**真正影响运行时产品的**：
  - `@tiptap/core <3.30.5`：Markdown 解析 ReDoS（富文本编辑器在用）→ 升 ≥3.30.5；
  - `prosemirror-view <1.42.3`：**XSS**（tiptap 底层）→ 升 ≥1.42.3；
  - `dompurify <=3.4.16`：多个 sanitize bypass（`SAFE_FOR_TEMPLATES`、`FORBID_TAGS` bypass 等）→ 升 ≥3.4.17（`@types/dompurify` 是官方废弃 stub，应删除）；
  - `react-router 7.x` 5 条 high —— 但审核证实 react-router 仅被未使用的 shadcn 模板引用，建议直接移除依赖而非升级；
  - `lodash _.template` 代码注入 —— 需确认是否真进了 bundle，若仅传递依赖建议 override；
- 其余 high（vite/postcss/undici/ws/js-yaml/browserslist/nanoid/sharp/extract-zip/brace-expansion/tar/source-map-js）均为 dev/工具链暴露面，按批升级即可。
- CI 的 security job 用 `pnpm audit ... || true`（`.github/workflows/ci.yml` Job 6）——**告警等于不拦截**，这是 2C/57H 长期积压的制度原因。

## 4. 远程 Pages 部署分析（核心章节）：从"文档页"回到"应用本体"

### 4.1 现状链路（为什么会是一个落地页）

```
用户访问 pai.yyc3.vip
  └─ GitHub Pages（build_type=workflow，cname=pai.yyc3.vip，HTTPS enforced，证书至 2026-12-30）
      └─ 仓库 YYC-Cube/YYC3-PAI-AI 的 .github/workflows/pages.yml
          └─ push main 触碰 public/** 时，upload public/ 整目录
              └─ public/index.html（2009B 品牌落地页）+ CNAME + yyc3-family.png(788KB) + 图标
```

这张落地页本身没有"坏"——它正确链接到新仓库地址、正常渲染。问题是**它只是品牌页，不是任何项目的产品**：
- 本地 React 前端的 CI（`.github/workflows/ci.yml` Job 4）有完整设计：build → `cp public/CNAME dist/` → `configure-pages@v5` → upload `dist/` → `deploy-pages@v4`，但随旧仓库删除，该流水线**一次都没在线上跑过**；
- Python 平台的 dashboard/desktop 是独立应用，也没走这个域名；
- 结果：域名被"占位"，访问者看到的永远是文档页。
