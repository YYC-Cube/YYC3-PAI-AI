- Git 面板链：init → 写文件 → add → commit（oid 回传）→ 状态矩阵 → 远端 CORS 守卫
- 数据同步编排：双适配器聚合 → 批处理 → completed + 进度事件流

## 五、本役真 bug（#29–#36，全部源码修复 + 回归锁定）

| # | 缺陷 | 严重度 |
|---|---|---|
| 29 | 加密导出跨会话必败（iv/salt 丢弃+全零伪造）——重写为口令自含（PBKDF2-210k + 随机盐/iv） | P0 安全承诺 |
| 30 | IndexedDB 恢复双重信封（往返数据损坏） | P1 |
| 31 | CRDT 建档死锁（UI 永远无法开始协作） | P1 |
| 32 | 音频上传自毁 blob URL（上传即不可播放） | P1 |
| 33 | Node 20 webcrypto 品牌校验差异（.buffer 直传被拒，双平台实证） | P1 兼容 |
| 34 | executeWorkflow 传 immer 撤销 draft → 执行链全部 proxy-revoked 必败（P0 回归，深度测试逼出） | P0 |
| 35 | retryNode 冻结只读 TypeError + 完成计数从不落库 | P1 |
| 36 | naturalLanguage 成功分支写冻结 result 吞错为失败（历史双条） | P1 |

配套修复：workflow 执行链「冻结感知可变化」方案（冻结走拷贝回写、未冻结注入直传保 live 契约）+ 节点终态/执行计数落库 + locked-缺陷断言改写为修复后语义 + AI 写作提示词损坏（#23 系）等甄别项。
